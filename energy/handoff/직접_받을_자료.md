# 직접 내려받아 Claude에게 넣어 줄 자료

> 아래 자료는 로그인·회원가입·이용 신청이 필요해서 Claude가 대신 받을 수 없다. 받은 파일은 **이름을 바꾸지 말고 그대로 채팅창에 첨부**하면 된다(CSV·XLSX·ZIP 모두 가능). 사이트의 메뉴 이름은 바뀔 수 있으니, 비슷한 이름을 찾으면 된다.
> 우선순위: ★★★ 발표 전에 있으면 결과가 크게 좋아짐 · ★★ 있으면 좋음 · ★ 발표 후 과제

## ★★★ 1. 기상청 시간별 관측 자료 (2024~2025년)
- **왜**: 발전 계획 AI의 태양광·풍력 예측에 날씨를 넣는다. 지금은 날씨가 없어서 태양광·풍력은 "지난주 값"과 비슷한 수준이다.
- **어디서**: 기상자료개방포털 <https://data.kma.go.kr> → 회원가입·로그인 → 데이터 → 기상관측 → **지상(종관, ASOS) → 시간 자료**
- **무엇을**: 기간 2024-01-01 ~ 2025-12-31 / 지점: 시도별 대표 지점(서울, 인천, 수원, 춘천, 강릉, 청주, 대전, 홍성, 전주, 광주, 목포, 대구, 안동, 부산, 울산, 창원, 제주 등 가능한 만큼) / 항목: **기온, 풍속, 습도, 강수량, 일조, 일사, 전운량**
- **형식**: CSV 다운로드. 기간이 길어 나눠서 받아야 하면 여러 파일로 받아도 된다.

## ★★★ 2. 기상청 단기예보 과거 자료 (2024년, 가능하면 2025년도)
- **왜**: 지금 태양광 성능은 "그 시각의 실제 날씨"를 넣은 결과다. 실제로 하루 전에 쓸 수 있는 **예보**를 넣어야 진짜 운영 성능을 잴 수 있다(발표에서 가장 많이 나올 질문).
- **어디서**: 기상자료개방포털 → 데이터 → 기상예보 → **단기예보**(2021년 6월 이전은 "(구)동네예보") — 또는 기상청 API허브 <https://apihub.kma.go.kr> (회원가입 후 파일 내려받기)
- **무엇을**: 발표시각 **14시(1400)** 예보, 기간 2024-01-01 ~ 2024-12-31, 1번과 같은 지역(시도 대표 격자 또는 지점), 항목: **기온(TMP), 하늘상태(SKY), 강수형태(PTY), 강수확률(POP), 습도(REH), 풍속(WSD)**
- **참고**: API 인증키를 발급받았다면 **키를 채팅에 붙여 넣지 말고** 알려만 주면, Claude가 띄우는 보안 입력창에 넣는 방식으로 연결할 수 있다.

## ★★ 3. 전력거래소 전력통계정보시스템(EPSIS) 자료
- **어디서**: <https://epsis.kpx.or.kr> (대부분 로그인 없이 엑셀 다운로드 가능하지만, Claude의 환경에서는 접속이 막혀 있다)
- **3-1. 2025년 일별 전력수급(공급능력·최대전력·공급예비율)** → 현재 이전 값으로 유지 중인 `supply_daily_2025.csv`를 바꿀 수 있다.
- **3-2. 시간별 전력수요 2022~2024년** → 수요 예측 AI의 학습 기간을 1년에서 3~4년으로 늘린다(계절 패턴 학습).
- **3-3. 하루 전 수요 예측(공식) 2025년** → 우리 수요 AI와 공식 예측을 같은 조건에서 비교한다.
- **3-4. 연료원별 시간별 발전량 2025년** → 우리가 세운 발전 계획과 실제 발전소 운전을 비교한다.

## ★★ 4. 공공데이터포털 오픈API (로그인 후 "활용신청", 대부분 자동 승인)
- **어디서**: <https://www.data.go.kr> → 아래 번호 검색 → 오픈API 탭 → 활용신청 → 마이페이지에서 인증키 확인
- 15086088 한국전력거래소_시간별 계통한계가격(SMP) → 발전 계획의 비용 계산(연료비가 싼 발전소부터 쓰는 계획)
- 15150382 한국전력거래소_하루전 발전계획용 수요예측 → 3-3 대신 사용 가능
- 15139872 한국중부발전_연료전지 발전실적, 15139102 소수력 일자별 발전실적 → 이상 후보 알림 보강
- **인증키는 채팅에 붙이지 말 것.** 받았다고 알려 주면 Claude가 보안 입력창을 띄운다.

## ★ 5. 발전소 정비·고장 기록 (발표 후 과제)
- **왜**: 이상 후보 알림이 실제 고장이었는지 확인하는 "정답" 자료. 공개 자료에는 화력·복합 설비 정비 기록만 있다.
- **어떻게**: 정보공개포털 <https://www.open.go.kr> 에서 한국중부발전에 "연료전지·풍력·소수력 설비 정비·정지 이력(2023.11~2026.8)" 정보공개청구. 처리에 10일 이상 걸린다.
