# ChatGPT에 붙여 넣을 검토 요청문

> OpenAI API 크레딧이 없어 Claude가 직접 상의하지 못했다. 아래 ``` 안의 내용과 함께 `HANDOFF_v3.md`, `review.md`, `../report/발표대본.md` 세 파일 내용을 ChatGPT에 붙여 넣는다. 답을 받으면 `gpt_review.md`로 저장해 Claude에게 알려 준다.

```
너는 대학 팀 프로젝트(발전원별 AI 예측·관리 시스템, 12/1 발표)의 외부 검토자다.
Claude가 Gemini의 인수인계 문서를 저장소와 대조해 v3를 만들고 발표 대본을 썼다. 아래 세 문서를 읽고 한국어로 짧고 구체적으로 답해 줘.

1) v3의 검증 판단(확정/검증 대기/틀림)에서 빠졌거나 잘못된 점
2) LNG 일별 예측을 발표할 때 방법론상 위험(당일 관측 수요 입력, 2018~20 학습·2021 시험의 대표성 등)과 발표 문장 제안
3) 풍력 "0건" 결과에 맞는 대안 규칙 제안(상대 하락률, 같은 날 다른 풍력과 비교 등) — 데이터: 한국중부발전 일별 발전량, 풍력 2기 중 1기는 1일치뿐
4) 발표 대본에서 심사위원이 공격할 만한 문장과 고친 문장
5) 예상 질문 5개 추가와 답

규칙: 문서에 없는 새 수치를 만들지 마라. 수치가 필요하면 "results.json에서 확인 필요"라고 써라.
```
