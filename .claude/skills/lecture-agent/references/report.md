# 분석 보고서·제안서 작성

출처: 아이디어톤 1회차 "파이프라인과 보고서" (notes/ideathon/20261106.html)

## 5단계 표준 절차

| 단계 | 핵심 과업 | 대표 기법 | 보고서에 남는 산출물 |
|---|---|---|---|
| 1. 문제 정의·가설 | 현상 진단, 기존 방식의 한계, 연구 질문·검증 가설 | 문헌 조사, 이해관계자 분석, 로직 트리 | 배경·목적, 핵심 질문, 분석 프레임워크 그림 |
| 2. 데이터 수집·전처리 | 여러 출처 확보, 시간·공간 단위 맞추기, 이상치·결측 정리 | Open API, 크롤링, min-max / z-score 정규화 | 데이터 명세표(출처·기간·표본 수), 전처리 설명 |
| 3. 탐색·실증 분석 | 패턴 파악, 시차 규명, 순효과 분리 | 텍스트 마이닝, TLCC, DID, 회귀 | 상관 프로파일, 효과 추정표, 회귀 결과 |
| 4. 모델링·시뮬레이션 | 예측, 시나리오별 민감도, 최적화 | 미분방정식, 탄력성 모형, 최적화(TSP 등) | 시나리오 비교표, 민감도 그래프 |
| 5. 실행 전략·환류 | 로드맵, 자원 배분, KPI, 리스크 | 비용편익분석, 액션 매트릭스, 사후 평가 설계 | 실행 계획표, 협업 구조, KPI 관리 체계 |

## 단계별 점검

- **문제 정의가 구체적인가**: 측정 대상, 기간, 목표 변수가 정해져 있다 (막연한 현황 나열 X).
- **데이터 대표성·윤리**: 표본 편향을 점검하고, 개인정보 비식별화와 API 약관을 지킨다.
- **상관과 인과 구분**: 대조군이나 시차 검증으로 내생성을 통제한다.
- **모델 가정 투명성**: 시뮬레이터에 넣은 파라미터의 근거와 한계를 적는다.
- **실행 가능성**: 결과가 실제 예산·시간·제도 제약 안에서 돌아가는 대안으로 이어진다.

## 섹션 구성 (두괄식)

1. **핵심 요약**: 1쪽 이내. 문제, 핵심 발견(3줄), 제안, 정량적 기대 효과.
2. **서론·문제 정의**: 배경, 기존 방식의 한계를 데이터로 지적하고, 분석 질문을 선언한다.
3. **데이터·방법론**: 출처, 기간, 표본 크기, 전처리, 기법을 고른 이유.
4. **실증 결과**: 차트와 통계량(상관계수, 회귀계수, p값, 오차 지표)으로 입증한다.
5. **모델링·솔루션**: 시뮬레이션·최적화 결과, 실행 전략, **대안 A/B/C 비교표**.
6. **결론·한계**: KPI 모니터링 방안, 데이터·모델의 한계, 후속 과제.

뼈대:

```markdown
## <제목> 분석 보고서
### 핵심 요약
- 배경·핵심 문제 / 주요 발견 3줄 / 제안과 기대 효과(수치)
### 문제 정의와 분석 프레임워크
- 현황과 기존 방식의 한계 / 연구 질문·가설 / 분석 흐름도
### 데이터와 전처리
- 데이터셋 명세(출처, 기간, 관측치 수, 핵심 변수) / 결측·이상치·정규화 방법
### 분석 결과
- 기법별 결과 / 종합 시사점
### 시뮬레이션과 제안
- 시나리오별 기대 성과 비교 / 실행 로드맵 / 이해관계자 역할
### 성과 관리와 한계
- KPI와 사후 검증 설계 / 가정의 한계와 보완 계획
```

## 시각화·근거 체크리스트

- **차트 제목에 결론을 쓴다**: "방문객 추이" 대신 "바이럴 정점 7일 뒤 2030 방문객 34% 급증".
- 모든 축에 변수명과 **단위**(천 명, 백만 원, %, kWh 등)를 적는다.
- **기준선**: 시계열에는 개입 시점(세로 점선)이나 평균선(가로 점선)을 넣고, 효과 분석에는 대조군이나 반사실 추정선을 같이 그린다.
- **통계량**을 본문·캡션에 쓴다: r, R², 회귀계수, p값 (예측이면 MAE/RMSE 등).
- **재현성**: 수집부터 시뮬레이션까지 코드가 처음부터 끝까지 오류 없이 다시 돌아간다.

## 자가 점검

- [ ] 모든 주장이 추측이 아니라 본문의 데이터·표·차트·시뮬레이션에 근거하는가?
- [ ] 정성 분석에서 얻은 인사이트가 정량 모델의 변수와 최종 제안에 실제로 반영되었는가?
- [ ] 대조군과 비교 기간(처치 전후)이 타당한가?
- [ ] 시뮬레이션 파라미터와 제약 조건이 현실적인 범위인가?
- [ ] 요약만 읽어도 문제, 근거, 제안, 기대 효과가 보이는가?
