## 분석 5단계 사이클

1. **질문하기**: "무엇을 알고 싶은가"를 측정 가능한 문장으로 쓴다.
2. **살펴보기**: `shape`, `info()`, `describe()`, 결측, 분포 모양(롱테일 여부), 다중 라벨, IQR 이상치를 본다.
3. **시각화하기**: 히스토그램, 롱테일이면 로그 스케일, 범주 막대, 상자 그림, 시계열 선.
4. **결론 내리기**: 질문에 대한 답과 근거, 한계를 적는다.
5. **반복하기**: 결론에서 나온 새 질문으로 다시 시작한다.

노트북 구성: 제목·질문 → 데이터 불러오기 → 품질 점검표 → 탐색 → 시각화 → 결론·한계 (마크다운 셀로 미니 보고서).

## 분석 프레임워크: 세 관점

| 관점 | 질문 | 데이터 예 | 기법 예 |
|---|---|---|---|
| 질문과 대응 (Why/What) | 사람들은 왜 반응했나? | 댓글, 게시글, 스크립트 | 형태소 분석(kiwipiepy), 로그 승산비, 의미 연결망 |
| 행동과 실증 (Who/How) | 실제 행동·지표가 바뀌었나? | 검색량, 방문객, 카드 결제 | 정규화 중첩, TLCC, DID, ITS |
| 모델링과 최적화 (When/Where) | 앞으로 어떻게 되고, 어떻게 배분하나? | 일별 시계열, 좌표·이동시간 | SIR·미분방정식, 탄력성 회귀, TSP/선택적 순회 |

## 전처리 함정

- **명절·휴일 착시**: 통신 방문자 통계는 귀성객이 섞여 튄다. "방문자 1인당 지출액", "100명당 내비 검색 수" 같은 **교차 진단 지표**로 진짜 수요인지 확인하고, 아니면 보간 등으로 보정한다.
- **세로형 공공데이터**: 피벗해서 일별 시계열로 바꾼 뒤 병합한다.
- **단위가 다른 시계열 비교**: min-max나 z-score로 정규화한 뒤 겹쳐 그린다.
- **결측 코드·인코딩**: -999 같은 센서 결측 코드, CP949↔UTF-8, 유니코드 정규화(NFC/NFD 파일명)를 먼저 점검한다.

## 인과·시차 검증

- **TLCC(시차 교차상관)**: 시차 k를 바꿔 가며 상관을 구해 최적 시차 k*(골든타임)를 찾는다.
- **로그-로그 회귀**: 계수 = 탄력성 (X가 1% 변할 때 Y가 몇 % 변하나).
- **DID(이중차분법)**: 처치군·대조군 × 전·후. 대조 지역(예: 경주 대 안동)은 처치 전 추세가 비슷해야 한다.
- **ITS(단절 시계열)**: 개입 시점 전후 수준·기울기 변화를 회귀로 추정한다.

## 수리 모델 고르기

- **목적부터 정한다.** 이해 지향형(메커니즘 설명: 파라미터가 해석 가능해야 함)인지, 응용 지향형(예측 성능이 중요)인지.
- **망치 함정**: 표본 50개에 딥러닝, 정적 분류에 미분방정식처럼 아는 도구에 문제를 끼워 맞추지 않는다.
- **기준선 비교 필수**: 직전 값 그대로, 단순 평균, 선형회귀보다 나아야 한다. 알려진 극한 조건에서 상식과 어긋나면 결함 신호다.
- 도구 지도: 방정식·커브 적합(SciPy) / 미분방정식(SymPy, SciPy) / 확률·마르코프·대기행렬 / 회귀·검정(statsmodels) / 시계열 분해·SARIMAX·상태공간 / 머신러닝: 분류·회귀·군집(PCA+GMM)·차원축소(scikit-learn) / 네트워크 중심성(NetworkX) / 행위자 기반 모델.

## 모델 평가

- **이해 지향형**: 곡선이 점을 지나가는지보다, 추정된 파라미터가 물리적으로 말이 되는지(음수면 안 되는 값이 음수인지 등), 독립적인 관측과도 맞는지를 본다.
- **통계 추론**: p값·신뢰구간이 유효하려면 잔차가 정규성·등분산·독립·선형 가정을 만족해야 한다. 잔차 산점도와 Q-Q plot으로 확인한다.
- **응용(예측)**: 훈련 점수는 보증이 안 된다. 한 번도 보지 않은 테스트 데이터 성능과 오류의 실제 비용으로 판단한다.
- **시계열은 `TimeSeriesSplit`(전진 검증)**으로 미래 정보 누수를 막는다. 스케일링도 각 폴드의 훈련 구간에서만 fit한다 (`make_pipeline`). 지연 특징(lag1, lag7)은 `shift`로 만든다.
- **분류 지표**: 불균형 데이터에서 정확도는 착시를 만든다 (양성 1%면 전부 음성이라고 해도 99%). 재현율(놓치면 안 될 때: 이상 탐지, 경보), 정밀도(오경보가 비쌀 때), F1, ROC-AUC를 목적에 맞게 고른다.
- **복잡도 균형**: AIC = −2ℓ + 2k (예측 목적), BIC = −2ℓ + k·ln n (참 구조 선택, 더 엄격). 변수를 추가했으면 널 모델과 우도비 검정으로 비교한다.
